# Privacy Data Map

## Data collected by Supernova servers

**None.** Product has no backend and no network client.

## On-device storage

| Data | Location | Purpose | Leaves device? |
|------|----------|---------|----------------|
| Favorite emoji IDs | UserDefaults (local) | User favorites | No |
| Recent emoji IDs | UserDefaults (local), bounded | Recents row/category | No |
| Selected theme ID | UserDefaults (local) | Theme preference | No |
| Selected category ID | UserDefaults (local) | Restore category | No |

## Not stored

- Keystrokes / typed text
- Surrounding text / document proxy content
- Host app identity
- Contacts, photos, location, mic, camera
- Advertising IDs
- Analytics events

## Entitlements / permissions

- Keyboard: no Full Access (`RequestsOpenAccess=false`)
- No privacy usage description keys for camera/mic/photos/contacts/location in MVP Info plists

## Third parties

None in MVP.
